Early-flow launch sniper + dip-rider pump.fun paper trading bot. It paper-trades 10 SOL on a replay of pump.fun bonding-curve data: it buys only launches whose curve already holds a few SOL, whose creator put in a sane create-slot buy, and which so far have exactly two distinct non-creator buyers — then pyramids winners and exits mechanically (+30% take-profit, -20% stop, 3% trailing stop, 45-slot max hold). A second leg buys big-curve coins (60+ SOL real reserves) that proved strength, pulled back hard from their peak, and are ticking up again on fresh flow.

## Run it

```sh
node main.ts
```
